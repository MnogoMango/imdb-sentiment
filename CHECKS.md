# Проверка проекта

Проверено в локальном окружении Poetry `.venv`, Python 3.12.14:

- `poetry install`, затем `poetry sync`: успешно.
- `poetry check --lock`: успешно.
- `pre-commit install`: hook установлен в локальный Git-репозиторий.
- `pre-commit run --all-files`: Ruff lint, Ruff format, Mypy, Tests — Passed.
- `pytest --cov=imdb_sentiment`: 15 passed, покрытие 93%.
- `poetry build`: wheel и sdist собраны.
- `imdb-sentiment --help`: CLI доступен.

Тесты проверяют очистку и её идемпотентность, пропуски и неизвестные метки,
конфликтующие дубликаты, воспроизводимость и непересечение выборок,
отсутствие признаков из test в словаре TF-IDF, обучение и сериализацию,
инференс, отдельную оценку test, защиту от изменённого CSV и перезаписи запуска.

Тестовое обучение выполнено на синтетических данных. Полный IMDB CSV не был
предоставлен в рабочую среду, поэтому реальный эксперимент здесь не повторён.
Матрица Python 3.11/3.12/3.13 настроена в GitHub Actions, но удалённый CI ещё
не запускался. Файлы `.git`, `.venv`, кэши и бинарные сборки в архив не включены;
после распаковки выполните команды быстрого старта из README.md.
